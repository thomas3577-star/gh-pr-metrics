# What's improved over pr-metrics-agent

gh-pr-metrics is the successor to [pr-metrics-agent](https://github.com/thomas3577-star/pr-metrics-agent):
from a repo health check to a team performance tool.

| # | Differentiator | Old Version | Newer Version |
|---|---|---|---|
| 1 | **Set up in minutes** | Virtual environment, 5 packages to install, a GitHub token pasted into a file | Python + GitHub CLI you already sign in to. **Nothing to install, no tokens to manage** |
| 2 | **Answers every question that matters** | 2 of 6 questions | **All 6**: speed, bottlenecks, skipped reviews, stability, PR size, piling-up work |
| 3 | **Built for real teams** | One public repo at a time, github.com only | **Many repos, a report per repo**, filtered to your team; works on **company GitHub servers** |
| 4 | **Speaks your sprint language** | A rolling 30-day window | **Your sprint length or a month**, by date; ask for "since start", "last 3 months" or exact dates in plain English |
| 5 | **Numbers you can trust and prove** | Some thresholds from a 2006 study; checking meant reading code | **Benchmarks only from current, cited research.** Every PR's workings visible, and one-click CSV to verify in Excel |

*Same engine size, several times the value. Faster to start, wider in reach, and every number defensible.*
