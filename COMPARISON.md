# What's improved over pr-metrics-agent

gh-pr-metrics is the successor to [pr-metrics-agent](https://github.com/thomas3577-star/pr-metrics-agent):
from a repo health check to a team performance tool.

| #   | Differentiator                                 | Old Version                                                                                              | Newer Version                                                                                                                                                                                 |
| --- | ---------------------------------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Ready in minutes**                           | A virtual environment, 5 packages to install, and a GitHub token pasted into a file before the first run | Nothing to install beyond Python and the GitHub CLI, no tokens to paste. <br/>Copy one settings file, type *"Run PR metrics"* in Copilot Chat                                                           |
| 2   | **All six questions, answered**                | Answered only <br/>How long does a PR take to merge?<br/>Are merged changes stable?                 | Enhanced to answer - <br/>Where does the time go: waiting for review, in review, or waiting to merge?<br/>Are reviews skipped? <br/>Are PRs small enough? <br/>Is unfinished work piling up? |
| 3   | **Your team, your repos, your server**         | One public repo at a time, on github.com only                                                            | Point it at every repo your team works in, on github.com or your company's GitHub server. List your people and everyone else drops out.                                                       |
| 4   | **Speaks in your sprints**                     | A rolling window of a set number of days, whatever your sprint                                                            | Columns that line up with your sprints: 1 week, 2 weeks or a month, starting on your sprint day.                                                                                              |
| 5   | **Question any number, get a straight answer** | A list of PRs, but no dates behind each number and no export; checking meant going back to GitHub                                                             | Ask the agent *"Why did #14815 wait 2 days for review?"* and check its reasoning, or download the PRs behind a median and check it in Excel in a minute.                                            |

*Faster to start, wider in reach, and it shows its working for every number it gives you.*
